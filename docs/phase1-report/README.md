# SP1 Phase-1 report — build notes

The report is `phase1-report.tex`; the deliverable is the compiled `phase1-report.pdf`.
Numbers in it are **generated, never hand-edited** (see `docs/phase1-report/tables/`).

## Build

```bash
# 1. produce the results the pipeline writes (datasets are git-ignored)
python subprojects/sp1-data-forecasting/scripts/fetch_datasets.py --dataset us-boulder-ev
python subprojects/sp1-data-forecasting/scripts/fetch_datasets.py --dataset us-palo-alto-ev
python subprojects/sp1-data-forecasting/scripts/run_sp1.py --dataset us-boulder-ev \
    --forecast-days 30 --train-window-days 180
python subprojects/sp1-data-forecasting/scripts/run_sp1.py --dataset us-palo-alto-ev \
    --forecast-days 14 --train-window-days 180

# 2. regenerate figures and the LaTeX fragments (tables/ and figures/)
python subprojects/sp1-data-forecasting/scripts/make_figures.py
python subprojects/sp1-data-forecasting/scripts/make_report_tables.py

# 3. compile twice so \ref and \label settle
cd docs/phase1-report
xelatex phase1-report.tex
xelatex phase1-report.tex
```

## Verify the build

Do not trust "a PDF appeared"; check the log. The TeX log hard-wraps at about 79 columns, so
`Output written` can be split across two lines — read the page count with `pdfinfo` instead of a
single-line grep:

```bash
pdfinfo phase1-report.pdf | grep Pages
grep -c 'Overfull \\hbox' phase1-report.log      # expect 0
grep -n '^! ' phase1-report.log                  # expect no output
pdftoppm -png -r 70 -f 7 -l 7 phase1-report.pdf page   # eyeball a page
```

## Layout

| Path | Origin |
|---|---|
| `phase1-report.tex` | hand-written source |
| `tables/*.tex` | generated by `scripts/make_report_tables.py` from `data/interim/*.json` and `data/processed/*.csv` |
| `figures/*.png` | generated by `scripts/make_figures.py` |
| `*.aux`, `*.log`, `*.out` | LaTeX intermediates, git-ignored |

## House rules applied here

- Academic register, no meta-narrative about how the report was produced, and no whole-sentence
  bold (workspace `G-S-11`). The reproduction instructions that used to sit in the PDF live in this
  file instead.
- All quoted numbers come from pipeline artefacts through `tables/keynumbers.tex` (workspace
  `C-0009`).
- LaTeX is compiled with `xelatex` (workspace report rule).
